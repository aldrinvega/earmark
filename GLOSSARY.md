# Glossary

**Book**:
An audiobook served by Audiobookshelf. A Book can exist with audio only.
_Avoid_: "audiobook" as a separate thing from Book; "title"

**Textbook**:
The Pocket Book Studio EPUB of a Book's text. A Book gets read-along only when it has a Textbook.
_Avoid_: "ebook", "EPUB" (as the name for the linked text)
